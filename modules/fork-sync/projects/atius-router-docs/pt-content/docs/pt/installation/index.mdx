## Visão Geral

O Atius AI Router suporta múltiplos métodos de implantação. Você pode escolher a solução mais adequada com base no seu conhecimento técnico e cenário de uso.

<Callout type="tip">
**Recomendação para produção**: Para implantações em produção, recomendamos o **Docker Compose** com PostgreSQL e Redis externos. Veja [Docker Compose Deployment](/pt/docs/installation/deployment-methods/docker-compose-installation).
</Callout>
