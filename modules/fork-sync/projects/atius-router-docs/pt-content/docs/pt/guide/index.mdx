## Por que Atius AI Router?

O **Atius AI Router** é um fork de produção do [QuantumNous/new-api](https://github.com/QuantumNous/new-api) com:

- ✅ **Hardening de produção**: Configurações testadas em ambientes de alta carga
- ✅ **Documentação em PT-BR**: Suporte nativo para o português brasileiro
- ✅ **Compatibilidade total**: 100% compatível com a API OpenAI
- ✅ **Open-source**: Licença MIT, código auditável
