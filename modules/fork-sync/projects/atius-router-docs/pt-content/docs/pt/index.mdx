## Por que escolher o Atius AI Router?

O **Atius AI Router** é uma versão *hardened* do QuantumNous/new-api, otimizada para ambientes de produção. Agrega mais de 40 provedores de IA atrás de uma única API compatível com OpenAI/Anthropic, com:

- ✅ **Implantação em produção**: Configurações testadas em ambientes de alta carga
- ✅ **Compatibilidade total**: API 100% compatível com OpenAI e Anthropic
- ✅ **Suporte a múltiplos idiomas**: Documentação em PT-BR, EN, ZH e JA
- ✅ **Open-source**: Licença MIT, código aberto em [github.com/giovannimnz/router-ai-atius](https://github.com/giovannimnz/router-ai-atius)
