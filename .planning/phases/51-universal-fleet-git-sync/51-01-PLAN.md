## 2. Requirements & Guardrails

- **R01 - Dynamic Repository Discovery:** O motor deve escanear dinamicamente `~/GitHub` e identificar qualquer diretório que possua `.git/`, sem listas estáticas hardcoded.
- **R02 - Parallel Execution with Concurrency Cap:** O pull dos repositórios dentro de cada máquina deve ser executado em paralelo (jobs assíncronos), limitado a 3 ou 4 workers concorrentes para não saturar I/O e CPU.
- **R03 - Strict CPU Guardrail (<= 20%):** Toda execução no host e nós remotos deve rodar sob cgroups (`CPUQuota=20%`), `nice -n 19` e `ionice -c 3`.
- **R04 - Universal Client Alias & Hook:** O comando `git sync "<msg>"` deve funcionar a partir de qualquer repositório no Windows e no WSL, detectando o repositório corrente e disparando a frota via Landscape.
- **R05 - Safe Merge & Autostash Idempotency:** Nunca sobrescrever nem apagar arquivos de trabalho locais sem stash seguro (`git stash push -u`). Em caso de conflito, abortar o merge no nó remoto e preservar o estado sem quebrar a árvore.
- **R06 - Windows Zero-UI:** Nenhuma janela, terminal ou pop-up transitório deve ser aberto durante o disparo ou execução em segundo plano no Windows 11.
