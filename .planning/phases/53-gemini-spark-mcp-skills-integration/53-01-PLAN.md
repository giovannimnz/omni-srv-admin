# Plan 53-01: Gemini Spark MCP Gateway & Skills Integration

> Phase: 53-gemini-spark-mcp-skills-integration
> Status: planned
> Aligned with: fleet-gdrive (phases in a3a324f9-8f8a-4c21-a53e-6698061f49f0 & f142237d-3b70-443b-bb68-03ffe2912fb7)

## 1. Goal
Habilitar a conexão direta e soberana dos serviços MCP (`gbrain`, `obsidian`, `oci-admin`) e das 337 skills da ATIUS com o Google Gemini Spark (`https://gemini.google.com/spark/apps` e `https://gemini.google.com/spark/skills`).

## 2. Tasks

### Task 1: Edge Gateway Apache Rewrite Rules
- Arquivo: `modules/srv1-ops/apache/mcp.atius.com.br.conf`
- Adicionar rewrite rule para tradução de token de URL para cabeçalho `Authorization: Bearer <token>`:
  - Rota de path: `https://mcp.atius.com.br/spark/<token>/<service>`
  - Rota de query param: `https://mcp.atius.com.br/<service>?token=<token>`
- Garantir que o handshake inicial de MCP `initialize` receba `200 OK` diretamente no Gemini Spark sem acionar desafio `401`/`403` ou fluxo OAuth 2.1 não provisionado.

### Task 2: Skills Packaging & Direct Import no Spark
- Arquivo: `scripts/spark-skills-packager.py`
- Executar e validar a geração de bundles temáticos `.zip`:
  - `spark-skills-atius-fleet-ops.zip` (30 skills)
  - `spark-skills-gsd-spec-driven.zip` (99 skills)
  - `spark-skills-intelligence-brain.zip` (22 skills)
  - `spark-skills-devtools-automation.zip` (18 skills)
  - `spark-skills-general.zip` (168 skills)
- Documentar passo a passo de importação via botão `(↑)` em `gemini.google.com/spark/skills`.

### Task 3: Exposição de Skills via MCP Tool
- Documentar como o Gemini Spark invoca as skills dinamicamente via ferramentas do `gbrain` já conectadas (`list_skills`, `get_skill`).

### Task 4: Validação e Smoke Test
- Adicionar teste de conformidade ao script `modules/srv1-ops/scripts/mcp-conformance-smoke.py` validando acesso com token em URL/path.

## 3. Verification Criteria
- [ ] Conexão de teste HTTP simulando chamada do Spark responde com 200 OK e inicialização MCP.
- [ ] Bundles ZIP de skills gerados e íntegros em `build/gemini-spark-skills/bundles/`.
- [ ] Zero segredos ou tokens hardcoded persistidos em arquivos do Git.
