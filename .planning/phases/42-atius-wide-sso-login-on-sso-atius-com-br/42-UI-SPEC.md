## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, spinner border, tight metadata gaps. |
| sm | 8px | Field label-to-input gap, footer line gap, compact state rows. |
| md | 16px | Default form gaps, mobile page padding, shell inner padding. |
| lg | 24px | Card header/content horizontal padding, primary section spacing. |
| xl | 32px | Desktop vertical breathing room around the auth shell. |
| 2xl | 48px | Maximum top/bottom offset on tall desktop viewports. |
| 3xl | 64px | Reserved for page-level spacing outside this compact auth surface; do not use inside the login shell. |

Exceptions: preserve existing ATS compact values where already established: 12px for dense form stack gaps, 20px for auth shell padding on `sm+`, and 44px minimum pointer target for icon-only buttons and safety/action links.

## Typography

Use exactly these sizes and weights in the SSO surface.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Micro / metadata | 11px | 400 | 1.2 |
| Body / helper | 14px | 400 | 1.5 |
| Label / button | 14px | 600 | 1.2 |
| Heading | 20px | 600 | 1.2 |

Rules:

- No hero-scale typography. `sso.atius.com.br` is a utilitarian authentication page, not a landing page.
- Heading copy must fit in one or two lines inside a 448px shell and in a 320px mobile viewport.
- Standard terms stay in English when they are tooling terms: OIDC, Keycloak, RBAC, callback, redirect, cookie.

- Muted text: `#9ca3af`
- Low-priority text/footer: `#6b7280`

## Required Screens And States

| State | Visual Contract | Interaction Contract |
|-------|-----------------|----------------------|
| Logged out login | First viewport is the centered login shell. Atius mono horizontal logo at top, 11px tagline, 20px heading `Entrar na Atius`, safe destination row, primary CTA. No hero section, product tour, marketing grid, or split layout. | CTA starts the OIDC Authorization Code Flow. If `return_to` is missing, use the default allowlisted destination. |
| Redirect target display/safety | Show one compact row inside the shell: `Destino seguro`, exact allowlisted host, and path if useful. Use muted text with one orange/success shield indicator. | Destination is read-only. Do not provide a freeform URL input. Truncate long paths visually, but validate the full URL server-side. |
| OIDC handoff/loading | Same dark gradient, no card shift. Use `Loader2`/spinner in orange, 14px body text, optional micro text naming `Keycloak`. | Disable CTA while redirecting. Prevent double-submit. Preserve validated state/return target server-side. |
| Invalid redirect | Same shell, destructive top border or inline alert, no automatic redirect. Heading `Destino nao permitido`. | Offer only allowlisted recovery actions: `Entrar pelo destino padrao` and `Voltar ao app de origem` if the referrer is allowlisted. |
| Auth error | Inline destructive alert above CTA; keep fields/CTA visible. Modal only for unrecoverable callback failure. | Let the user retry OIDC once. Do not reveal token, client, realm, stack trace, or upstream error details. |
| Logout complete | Success icon, heading `Sessao encerrada`, body text, primary action `Entrar novamente`, secondary action `Voltar para trade.atius.com.br`. | This state follows Keycloak logout plus legacy `.atius.com.br` and no-domain `auth-token` cleanup. No auto-login loop. |
| Already authenticated redirect | Loading state with `Sessao ativa. Redirecionando...`, safe destination row. | If destination is valid, redirect immediately. If invalid, stop at invalid redirect state. |
| Mobile | Shell uses full available width with 16px page padding and no horizontal scroll. Logo max height 36px. | All actionable controls have 44px minimum hit target. Text must wrap without overlapping icons. |
| Desktop | Shell max width 448px, centered both axes on the gradient background. | Keyboard tab order: CTA, secondary links, logout/retry controls. Focus ring uses orange accent. |

## Layout Contract

- Use one auth shell only: `w-full max-w-md`, centered in `min-h-screen`, with `bg-gray-900/35`, `border-gray-700/30`, and the existing ATS rounded shell.
- Do not nest cards inside cards. If a shadcn `Card` wrapper is used, keep it transparent like the current ATS login.
- Keep the first screen as the usable login experience. Supporting text is limited to one short helper line and the destination safety row.
- Use the existing Atius logo asset (`/mono-atius-horizontal.svg`) unless execution creates a specific SSO-safe Atius-wide logo. Alt text: `Atius`.
- Footer is optional and must be low contrast: `Atius SSO` or copyright text at 11px. Do not use slogans like `Seguro • Profissional • Confiavel` if they crowd mobile.
- Invalid redirect and auth error states must not resize the shell enough to push the primary action below the first mobile viewport.

## Component Inventory

| Component | Use |
|-----------|-----|
| `Button` | Primary CTA, retry, logout complete action. Use full-width primary CTA in login shell. |
| `Input` | Only if a local credential form remains necessary. Prefer Keycloak-owned credential entry through OIDC. |
| `Label` | Field labels and safety row labels. |
| `Alert` or inline status block | Invalid redirect, auth error, logout complete, OIDC callback failure. |
| `Dialog` | Only for unrecoverable/destructive confirmation. Do not use a modal for normal auth errors. |
| `Tooltip` | Optional for unfamiliar safety icons only. |
| `Skeleton` / spinner | Already-authenticated redirect, OIDC handoff, callback validation. |

Do not add third-party UI registries, animation libraries, or visual assets for this phase.

## Accessibility And Interaction

- Form controls and buttons must be keyboard reachable with visible orange focus states.
- Login and redirect status messages must be announced with `aria-live="polite"`; auth errors and invalid redirects use `role="alert"`.
- Spinner-only states must include visible text.
- Icon-only buttons require accessible names and 44px hit target.
- Color cannot be the only signal for safe/invalid redirect; pair icon, label, and copy.
- The page must work at 320px width, 390px mobile width, 768px tablet, and 1440px desktop without text overlap.

---

## Security UI Rules

- Never display raw `redirect`, `state`, `code`, `id_token`, `access_token`, `refresh_token`, client secret, JWT secret, cookie value, bearer token, or smoke credential.
- The UI may display an allowlisted host and normalized path, but not full query strings unless each key is explicitly allowlisted and redacted.
- Unknown host, protocol-relative URL, non-HTTPS URL, userinfo URL, and subdomain-confusion URL must render the invalid redirect state.
- Logout copy must say "limpar cookies Atius" at user level; internal cookie names stay out of UI.
- RBAC denial copy must say the user does not have access to that app, not that a permission flag failed.
