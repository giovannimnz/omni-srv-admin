<objective>
Implement the controlled remote bootstrap path: create the internal service CA
authority on `atius-srv-1`, create target-host keys/CSRs, sign per-host leafs,
install CA trust and leaf chains, with backups and rollback metadata.
</objective>

<tasks>

1. Write remote-safe bootstrap scripts.
   - Files:
     - `modules/fleet-pki/scripts/omni-fleet-pki-bootstrap.sh`
     - `modules/fleet-pki/scripts/omni-fleet-pki-host.sh`
   - Acceptance:
     - `set -euo pipefail`.
     - no private key printed.
     - no secrets in argv.
     - backup created before overwrite:
       `/root/.backups/omni-fleet-pki-YYYYmmddTHHMMSSZ/`.

2. Initialize CA authority on `atius-srv-1`.
   - Remote paths:
     - `/var/lib/omni-srv-admin/pki/private/`
     - `/var/lib/omni-srv-admin/pki/certs/`
     - `/var/lib/omni-srv-admin/pki/db/`
     - `/var/lib/omni-srv-admin/pki/crl/`
   - Acceptance:
     - root and issuing CA generated once, idempotently.
     - root private key is `root:root 600`.
     - issuing key is `root:root 600`.
     - CA certs are public-readable.
     - serial/index state exists and is backed up.

3. Generate host key/CSR on every target host.
   - Remote paths:
     - `/etc/omni-srv-admin/tls/<host-id>/server.key.pem`
     - `/etc/omni-srv-admin/tls/<host-id>/server.csr.pem`
   - Acceptance:
     - key owner is root, mode `600`.
     - CSR subject uses host ID.
     - CSR SAN extension matches inventory render.
     - private key never leaves target host.

4. Sign host CSRs on `atius-srv-1`.
   - Output:
     - `server.crt.pem`
     - `chain.crt.pem`
     - public peer cert copy in CA state.
   - Acceptance:
     - leaf profile uses `CA:FALSE`, `serverAuth`, `clientAuth`.
     - leaf lifetime is bounded, initially 397 days unless overridden.
     - command records SHA256 fingerprint and serial only.

5. Install CA trust and leaf chain on every host.
   - Paths:
     - `/usr/local/share/ca-certificates/atius-vpn-service-root-ca.crt`
     - `/usr/local/share/ca-certificates/atius-vpn-service-issuing-ca.crt`
     - `/etc/omni-srv-admin/tls/ca-chain.crt.pem`
     - `/etc/omni-srv-admin/tls/peers/<peer>.crt.pem`
   - Acceptance:
     - `update-ca-certificates` runs after copy.
     - every peer public leaf is copied as evidence/pinning material, not as a
       trusted root.

6. Update inventory and runbook.
   - Files:
     - `inventory/hosts/*.yaml`
     - `docs/operations/internal-service-pki.md`
   - Acceptance:
     - each host declares `pki.service_tls.enabled: true`.
     - docs include backup, rollback, rotation and validation commands.

</tasks>

<verification>

Read-only first:

```bash
PYTHONPATH=cli python -m omni fleet trust-pki preflight --json
```

Then, for each live mutation stage:

```bash
PYTHONPATH=cli python -m omni fleet trust-pki init-ca --dry-run --json
PYTHONPATH=cli python -m omni fleet trust-pki init-ca --execute --json
PYTHONPATH=cli python -m omni fleet trust-pki issue-host --host <host> --dry-run --json
PYTHONPATH=cli python -m omni fleet trust-pki issue-host --host <host> --execute --json
PYTHONPATH=cli python -m omni fleet trust-pki install-trust --host <host> --dry-run --json
PYTHONPATH=cli python -m omni fleet trust-pki install-trust --host <host> --execute --json
```

Remote checks:

```bash
ssh <target> 'sudo stat -c "%U %G %a %n" /etc/omni-srv-admin/tls/*/* /usr/local/share/ca-certificates/atius-vpn-service-*.crt'
ssh <target> 'sudo openssl verify -CAfile /etc/omni-srv-admin/tls/ca-chain.crt.pem /etc/omni-srv-admin/tls/<host>/server.crt.pem'
ssh <target> 'openssl verify -CApath /etc/ssl/certs /etc/omni-srv-admin/tls/peers/<peer>.crt.pem'
```

</verification>
