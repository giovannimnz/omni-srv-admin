<objective>
Add the versioned Omni Fleet PKI resource surface without touching live trust
stores: inventory-driven SAN rendering, dry-run plans, CA/CSR/leaf command
generation, secret redaction, and tests.
</objective>

<tasks>

1. Add `modules/fleet-pki/` scaffolding.
   - Files:
     - `modules/fleet-pki/README.md`
     - `modules/fleet-pki/templates/openssl-ca.cnf`
     - `modules/fleet-pki/templates/host-leaf.ext.cnf`
   - Acceptance:
     - Documents root/issuing CA paths, host leaf paths and no-secrets rule.
     - Templates enforce `CA:TRUE` for CAs and `CA:FALSE` for host leafs.

2. Add `omni fleet trust-pki` CLI group.
   - Files:
     - `cli/omni/fleet.py`
   - Commands:
     - `plan --json`
     - `preflight --json`
     - `render-host --host <id> --json`
     - `init-ca --dry-run|--execute`
     - `issue-host --host <id> --dry-run|--execute`
     - `install-trust --host <id|all> --dry-run|--execute`
     - `verify --host <id|all> --json`
     - `rollback-plan --host <id|all> --json`
     - `onboard-host --host <id> --db --execute --approve --json`
     - `reconcile-host --host <id> --json`
     - `rotate-host --host <id> --reason ip-change --db --execute --approve --json`
   - Acceptance:
     - Dry-run is default.
     - Mutating commands refuse to run without `--execute`.
     - Output contains fingerprints/paths only, never private key material.
     - New servers can be rendered from inventory or DbOmniFleet and queued as
       a complete onboarding sequence.
     - IP/SAN drift can be detected and queued as leaf rotation without
       reinstalling the CA chain by default.

3. Add inventory-driven SAN builder.
   - Files:
     - `cli/omni/fleet.py`
   - Source fields:
     - `id`
     - `aliases`
     - `access.vpn_ip`
     - `access.public_ip`
     - `access.legacy_vpn_ip`
     - `access.tailscale_ip`
     - `pki.service_tls.sans` if explicitly present
   - Acceptance:
     - `atius-srv-3` includes both `10.1.1.3` and legacy `10.1.1.7`.
     - `horistic-srv` uses SSH user `horistic` but certificate identity
       remains host ID/aliases/IPs.

4. Add allowlist templates for local-agent execution.
   - Files:
     - `cli/omni/fleet.py`
     - `modules/fleet-control-plane/README.md`
   - Command keys:
     - `omni.trust-pki.preflight`
     - `omni.trust-pki.ensure-key-csr`
     - `omni.trust-pki.issue-host`
     - `omni.trust-pki.install-leaf`
     - `omni.trust-pki.install-ca`
     - `omni.trust-pki.reconcile`
     - `omni.trust-pki.verify`
   - Acceptance:
     - Commands are argv arrays only, no shell strings.
     - PKI commands accept registered inventory/DbOmniFleet hosts, while CA
       stages remain constrained to `atius-srv-1`.

5. Add focused tests.
   - Files:
     - `cli/omni/tests/test_fleet_pki.py`
   - Coverage:
     - SAN rendering.
     - dry-run default.
     - explicit mutation gate.
     - redaction of private paths/content.
     - invalid host rejection.
     - command allowlist rendering.

</tasks>
