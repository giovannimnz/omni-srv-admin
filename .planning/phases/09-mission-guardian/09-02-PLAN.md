# 09-02: Disk fill forecasting + correlation analyzer

## objective

Adiciona 2 analyzers ao mission-guardian.py: (1) disk fill forecasting com
regressão linear (slope) sobre 7/30 dias; (2) correlation analyzer que detecta
"load subiu X% em Y min" mesmo abaixo do YELLOW threshold.

## read_first

- `modules/srv1-ops/scripts/mission-guardian.py` — código criado em 09-01,
  especialmente função `sample()` (retorna dict com 22 métricas) e
  `detect_anomalies()` (atualmente stub)
- `modules/srv1-ops/scripts/resource-governor-watchdog.py` — função
  `apply_cgroup_limits()` e `remove_cgroup_limits()` para referência
  (não usar nesta plan, mas entenda o flow)
- `~/.local/state/omni/mission-guardian.db` — schema com tabela `samples`
  contendo 22 colunas, queries com `WHERE ts >= datetime('now', '-N day')`

## acceptance_criteria

- Função `forecast_disk_fill(db, days=30)` retorna tupla
  `(days_to_90pct, days_to_95pct, current_pct, slope_pct_per_day)` com:
  - `slope_pct_per_day` calculado por regressão linear simples
    (least squares) sobre pelo menos 100 samples de disk_pct
  - `days_to_90pct` e `days_to_95pct` calculados com:
    `(target - current) / slope` se slope > 0, senão `float('inf')`
  - Se < 100 samples: retorna `(None, None, current_pct, None)` (insufficient)
- Função `detect_correlation(history)` retorna lista de anomalies:
  - "load_spike": load1 subiu > 50% em 5min (mesmo abaixo de 8.0)
  - "mem_drop": MemAvailable caiu > 30% em 10min
  - "fd_pressure": fd_used / fd_max > 0.8
  - "throttle_storm": cpu_throttled_total cresceu > 1000 em 1 ciclo
  - "oom_burst": oom_recent > 5
  - "jrn_blocked": jrn_blocked = 1 (journald > 1GB)
- Test command `python3 -c "from mission_guardian import forecast_disk_fill, detect_correlation; print(forecast_disk_fill.__doc__)"` exits 0
- Após 1h de operação, log mostra pelo menos 1 entry de cada analyzer
  (mesmo que "no anomalies")
- Forecaster emite warning level YELLOW em log se `days_to_90pct < 7`
- Forecaster emite warning level RED se `days_to_90pct < 3` ou `days_to_95pct < 7`

3. **Função `get_history(db, minutes)`**:
   ```python
   def get_history(db, minutes=10):
       """Retorna lista de dicts (rows) dos últimos N minutos."""
       cur = db.cursor()
       cur.execute("SELECT * FROM samples WHERE ts >= datetime('now', ?)",
                   (f'-{minutes} minutes',))
       cols = [d[0] for d in cur.description]
       return [dict(zip(cols, row)) for row in cur.fetchall()]
   ```
4. **Função `forecast_disk_fill(db, days=30)`**:
   ```python
   def forecast_disk_fill(db, days=30):
       """Linear regression on disk_pct. Returns (days_to_90, days_to_95, current, slope)."""
       cur = db.cursor()
       cur.execute("""SELECT ts, disk_pct FROM samples
                      WHERE ts >= datetime('now', ?)
                      ORDER BY ts""", (f'-{days} days',))
       rows = cur.fetchall()
       if len(rows) < 100:
           cur.execute("SELECT disk_pct FROM samples ORDER BY ts DESC LIMIT 1")
           cur_pct = cur.fetchone()
           return (None, None, cur_pct[0] if cur_pct else 0.0, None)
       # x = index (time order), y = disk_pct
       xs = list(range(len(rows)))
       ys = [r[1] for r in rows]
       n = len(xs)
       mean_x, mean_y = mean(xs), mean(ys)
       slope = sum((xs[i] - mean_x) * (ys[i] - mean_y) for i in range(n)) / \
               max(sum((x - mean_x) ** 2 for x in xs), 1e-9)
       # slope is pct per sample. samples are 60s apart, so pct per day = slope * 1440
       slope_per_day = slope * 1440
       current = ys[-1]
       days_to_90 = (90.0 - current) / slope_per_day if slope_per_day > 0 else float('inf')
       days_to_95 = (95.0 - current) / slope_per_day if slope_per_day > 0 else float('inf')
       return (max(days_to_90, 0), max(days_to_95, 0), current, slope_per_day)
   ```
5. **Função `detect_correlation(db, sample)`**:
   ```python
   def detect_correlation(db, sample):
       """Returns list of (level, msg) tuples for correlated events."""
       anomalies = []
       # 1. load spike: load1 atual vs load1 5min atrás
       hist_5 = get_history(db, minutes=5)
       if len(hist_5) >= 2:
           old = hist_5[0]['load1']
           cur = sample['load1']
           if old > 0 and (cur - old) / old > LOAD_SPIKE_THRESHOLD:
               anomalies.append(('YELLOW',
                   f'load_spike: load1 {old:.2f} -> {cur:.2f} ({(cur-old)/old*100:.0f}% in 5min)'))
       # 2. mem drop
       hist_10 = get_history(db, minutes=10)
       if len(hist_10) >= 2:
           old = hist_10[0]['mem_avail_mib']
           cur = sample['mem_avail_mib']
           if old > 0 and (old - cur) / old > MEM_DROP_THRESHOLD:
               anomalies.append(('YELLOW',
                   f'mem_drop: MemAvailable {old:.0f} -> {cur:.0f} MB ({(old-cur)/old*100:.0f}% drop)'))
       # 3. fd pressure (instant)
       if sample.get('fd_max', 0) > 0:
           fd_pct = sample['fd_used'] / sample['fd_max']
           if fd_pct > FD_PRESSURE_THRESHOLD:
               anomalies.append(('RED',
                   f'fd_pressure: {sample["fd_used"]}/{sample["fd_max"]} = {fd_pct*100:.0f}%'))
       # 4. throttle storm (delta vs 1 ciclo atrás)
       hist_1 = get_history(db, minutes=2)
       if len(hist_1) >= 2:
           old = hist_1[0].get('cpu_throttled_total', 0) or 0
           cur = sample.get('cpu_throttled_total', 0) or 0
           if cur - old > THROTTLE_STORM_DELTA:
               anomalies.append(('YELLOW',
                   f'throttle_storm: +{cur - old} throttled in 1 cycle'))
       # 5. oom burst
       if sample.get('oom_recent', 0) > OOM_BURST_THRESHOLD:
           anomalies.append(('RED',
               f'oom_burst: {sample["oom_recent"]} OOM events in last minute'))
       # 6. journald blocked
       if sample.get('jrn_blocked', 0) == 1:
           anomalies.append(('YELLOW',
               f'jrn_blocked: journald > 1GB disk'))
       return anomalies
   ```
6. **Função `detect_disk_forecast(db)`** — wrapper que retorna anomalies:
   ```python
   def detect_disk_forecast(db):
       d90, d95, cur, slope = forecast_disk_fill(db)
       if d90 is None:
           return []
       anomalies = []
       if d90 < 3 or d95 < 7:
           anomalies.append(('RED',
               f'disk_critical: current={cur:.1f}% slope={slope:.3f}%/day '
               f'-> 90%% in {d90:.1f}d, 95%% in {d95:.1f}d'))
       elif d90 < 7:
           anomalies.append(('YELLOW',
               f'disk_warning: current={cur:.1f}% slope={slope:.3f}%/day '
               f'-> 90%% in {d90:.1f}d'))
       return anomalies
   ```
