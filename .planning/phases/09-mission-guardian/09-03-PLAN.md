# 09-03: Auto-tune omni-* cpu.weight (predictive)

## objective

A cada 1h, mission-guardian observa cpu.weight efetivo por slice omni-* na
janela de 6h e ajusta os pesos PROATIVAMENTE: builds pesados ganham mais,
generics sobra, transfers perdem quando ocioso. Preserva limites absolutos
(cpu.max) e só mexe em pesos relativos (cpu.weight).

## read_first

- `modules/srv1-ops/scripts/resource-governor-patcher.py` — `PROFILE_LIMITS`
  com cpu_weight baseline: builds=200, interactive=500, transfers=100,
  generic=25, protected=1000. O patcher SETA esses pesos no startup e os
  mantém fixos.
- `modules/srv1-ops/scripts/mission-guardian.py` — após 09-01, tem funções
  `sample()`, `detect_anomalies()`, `respond()`. Main loop a cada 60s.
- `/sys/fs/cgroup/user.slice/user-1001.slice/omni-{builds,interactive,transfers,generic,protected}/cpu.stat` —
  contém `usage_usec` e `nr_throttled`. Parse para computar share efetivo.
- `/sys/fs/cgroup/user.slice/user-1001.slice/omni-{...}/cpu.weight` — write
  com `sudo tee` (atualmente 1000 max, 25 min)

## acceptance_criteria

- Função `compute_slice_share(cgroup_path, window_hours=6)` retorna tupla
  `(cpu_pct_avg, throttled_usec, nr_throttled)` parseando cpu.stat
- Função `compute_target_weights(shares)` retorna dict
  `{slice_name: new_weight}` com:
  - min weight = 25 (generic floor)
  - max weight = 1000 (interactive/protected ceiling)
  - ratios preservados — soma dos pesos fica igual à soma dos pesos
    baseline (±5% drift)
- Auto-tune roda a cada 1h (a cada 60 ciclos do mission-guardian) —
  check via `last_tune_ts` no DB
- Log mostra `auto-tune-applied` com diff dos pesos (ex:
  `builds 200->250 interactive 500->480 generic 25->25`)
- SOMENTE aplica se houve mudança significativa (>10% de desvio em algum
  slice) — senão log `auto-tune-skip no-significant-change`
- **NUNCA** mexe em `omni-protected` (sempre 1000) — verificado por guard
- **NUNCA** mexe em `cpu.max` (só `cpu.weight` e `io.weight`)
- **NUNCA** aplica se load1 > 6.0 (em contenção, tuning piora a situação)
- Test command `python3 -c "from mission_guardian import compute_target_weights; print(compute_target_weights.__doc__)"` exits 0

2. **Função `compute_slice_share(cgroup_path, window_hours=6)`**:
   ```python
   def compute_slice_share(cgroup_path, window_hours=6):
       """Returns (avg_cpu_pct, throttled_usec, nr_throttled) for the slice.

       Reads cpu.stat; 'avg' is a placeholder since cpu.stat is cumulative
       (rate requires delta tracking). For now, return totals + 'fair share'
       estimated from nr_throttled ratio.
       """
       stat_file = cgroup_path / 'cpu.stat'
       if not stat_file.exists():
           return (0.0, 0, 0)
       try:
           content = stat_file.read_text()
           stats = {}
           for line in content.splitlines():
               k, v = line.split()
               stats[k] = int(v)
           return (0.0,  # avg not computable from cumulative
                   stats.get('throttled_usec', 0),
                   stats.get('nr_throttled', 0))
       except Exception:
           return (0.0, 0, 0)
   ```

3. **Função `compute_target_weights(shares)`**:
   ```python
   def compute_target_weights(shares):
       """Returns {slice_name: new_weight}.

       Algorithm: slices that are THROTTLED get more weight; slices
       consuming lots of CPU but not throttled get less (idle rebalance).
       'shares' = {slice_name: (cpu_pct, throttled_usec, nr_throttled)}
       """
       targets = {}
       for name, (_, throttled_usec, nr_throttled) in shares.items():
           if name == AUTO_TUNE_PROTECTED_SLICE:
               targets[name] = AUTO_TUNE_MAX_WEIGHT  # never tune
               continue
           baseline = AUTO_TUNE_BASELINE_WEIGHTS.get(name, 100)
           if nr_throttled > 1000 and throttled_usec > 1000000:
               # throttled > 1s in window, give 25% boost
               targets[name] = min(int(baseline * 1.25), AUTO_TUNE_MAX_WEIGHT)
           elif nr_throttled == 0 and throttled_usec == 0:
               # idle, can take 20% cut (others benefit)
               targets[name] = max(int(baseline * 0.8), AUTO_TUNE_MIN_WEIGHT)
           else:
               targets[name] = baseline
       return targets
   ```

4. **Função `apply_weights(targets)`** — escreve via sudo tee:
   ```python
   def apply_weights(targets):
       """Writes cpu.weight to each omni-* cgroup. Returns list of changes."""
       changes = []
       for slice_name, weight in targets.items():
           cgroup = CGROUP_BASE / slice_name
           if not cgroup.exists():
               continue
           current = int((cgroup / 'cpu.weight').read_text().strip() or '100')
           if abs(current - weight) < int(AUTO_TUNE_BASELINE_WEIGHTS[slice_name] * 0.1):
               continue  # <10% change, skip
           try:
               subprocess.run(
                   ['sudo', 'tee', str(cgroup / 'cpu.weight')],
                   input=f'{weight}\n', capture_output=True, text=True, timeout=5,
               )
               changes.append(f'{slice_name} {current}->{weight}')
           except Exception as e:
               log(f'auto-tune-write-failed slice={slice_name} exc={e}')
       return changes
   ```

5. **Função `maybe_auto_tune(db, load1, cycle_count)`**:
   ```python
   def maybe_auto_tune(db, load1, cycle_count):
       if cycle_count % AUTO_TUNE_INTERVAL_CYCLES != 0:
           return
       if load1 > AUTO_TUNE_LOAD_LIMIT:
           log(f'auto-tune-skip load1={load1:.2f} > {AUTO_TUNE_LOAD_LIMIT}')
           return
       # Collect shares for all 4 non-protected slices
       shares = {}
       for slice_name in AUTO_TUNE_BASELINE_WEIGHTS:
           if slice_name == AUTO_TUNE_PROTECTED_SLICE:
               continue
           cgroup = CGROUP_BASE / slice_name
           shares[slice_name] = compute_slice_share(cgroup)
       # Check if protected exists (sanity)
       protected = CGROUP_BASE / AUTO_TUNE_PROTECTED_SLICE
       if protected.exists():
           shares[AUTO_TUNE_PROTECTED_SLICE] = (1000.0, 0, 0)
       targets = compute_target_weights(shares)
       changes = apply_weights(targets)
       if changes:
           log(f'auto-tune-applied {" ".join(changes)}')
       else:
           log(f'auto-tune-skip no-significant-change')
       # Record event
       db.execute(
           "INSERT OR IGNORE INTO events (ts, level, source, message) VALUES (?, ?, ?, ?)",
           (datetime.now().astimezone().isoformat(), 'INFO', 'auto-tune',
            f'changes={len(changes)} load1={load1:.2f}'),
       )
       db.commit()
   ```

6. **Integrar no main loop**: após `respond(anomalies)`, chamar
   `maybe_auto_tune(db, sample['load1'], cycle_count)`. Incrementar
   `cycle_count` no estado.
