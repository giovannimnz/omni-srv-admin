# 09-01: Mission Guardian daemon (core)

## objective

Daemon Python 24/7 que amostra 9 métricas a cada 60s e persiste em SQLite
local. Substitui a missão 4h ad-hoc por infraestrutura permanente.

## read_first

- `modules/srv1-ops/scripts/resource-governor-watchdog.py` — pattern established
  para daemon com poll loop + signal handling + append_log + state throttled
- `modules/srv1-ops/scripts/resource-governor-patcher.py` — pattern para
  INVIOLABLE_PATTERNS + cgroup interaction
- `modules/srv1-ops/configs/resource-governor.env` — padrão de config file
- `~/.logs/srv1-mission-4h/consolidated.log` — formato de output esperado
- `~/.local/state/omni/resource-governor-watchdog.json` — exemplo state file

## acceptance_criteria

- `python3 -c "import ast; ast.parse(open('modules/srv1-ops/scripts/mission-guardian.py').read())"` exits 0
- File `modules/srv1-ops/scripts/mission-guardian.py` ≥ 350 lines
- File `modules/srv1-ops/configs/mission-guardian.env` exists with all required keys:
  `RG_MG_POLL_INTERVAL_SEC=60`, `RG_MG_DB_PATH`, `RG_MG_RETENTION_DAYS=30`,
  `RG_MG_FALLBACK_TELEGRAM_CHAT`, `RG_MG_FALLBACK_INVIOLABLE_HOOK`
- Daemon ao rodar 5min cria `~/.local/state/omni/mission-guardian.db` SQLite
  com schema: `samples(ts, load1, load5, load15, mem_avail_mib, disk_pct,
  swap_pct, psi_io, psi_mem, tcp_estab, fd_used, fd_max, net_rx_kbs, net_tx_kbs,
  cpu_throttled_total, oom_recent, jrn_blocked, n_procs, top_cpu_comm,
  top_cpu_pct, top_mem_comm, top_mem_mib)`
- systemd user timer `mission-guardian.timer` está active e `next` < 90s
- Log `~/.logs/resource-governor/mission-guardian.log` mostra
  `mission-guardian-start poll=60s db=... retention=30d` na primeira execução
- Após restart, daemon lê `last_state` do DB e continua de onde parou
  (sem duplicar ou perder samples)

## action

Criar `modules/srv1-ops/scripts/mission-guardian.py` com a estrutura:

1. **DEPS**: json, sqlite3, signal, time, subprocess, os, shutil, statistics
   (stdlib only, sem dependência externa)
2. **CONFIG_PATH**: `Path(__file__).parent.parent / 'configs' / 'mission-guardian.env'`
3. **DEFAULTS** dict com:
   - `RG_MG_POLL_INTERVAL_SEC: '60'`
   - `RG_MG_DB_PATH: str(Path.home() / '.local' / 'state' / 'omni' / 'mission-guardian.db')`
   - `RG_MG_RETENTION_DAYS: '30'`
   - `RG_MG_FALLBACK_TELEGRAM_CHAT: ''`
   - `RG_MG_FALLBACK_INVIOLABLE_HOOK: '/home/ubuntu/scripts/inviolable-watchdog.sh'`
4. **Função `load_config()`** — mesmo pattern do watchdog (lê env file, override DEFAULTS)
5. **Função `init_db(db_path)`** — cria SQLite com schema:
   ```sql
   CREATE TABLE IF NOT EXISTS samples (
     ts TEXT PRIMARY KEY,
     load1 REAL, load5 REAL, load15 REAL,
     mem_avail_mib REAL, disk_pct REAL, swap_pct REAL,
     psi_io REAL, psi_mem REAL,
     tcp_estab INTEGER, fd_used INTEGER, fd_max INTEGER,
     net_rx_kbs REAL, net_tx_kbs REAL,
     cpu_throttled_total INTEGER, oom_recent INTEGER, jrn_blocked INTEGER,
     n_procs INTEGER,
     top_cpu_comm TEXT, top_cpu_pct REAL,
     top_mem_comm TEXT, top_mem_mib REAL
   );
   CREATE INDEX IF NOT EXISTS idx_samples_ts ON samples(ts);
   CREATE TABLE IF NOT EXISTS events (
     ts TEXT, level TEXT, source TEXT, message TEXT,
     PRIMARY KEY (ts, source, message)
   );
   ```
6. **Função `sample()`** retorna dict com 22 métricas. Implementação:
   - load1/5/15: `os.getloadavg()`
   - mem_avail_mib: parse `/proc/meminfo` MemAvailable
   - disk_pct: `shutil.disk_usage('/').used / total * 100`
   - swap_pct: (SwapTotal - SwapFree) / SwapTotal
   - psi_io, psi_mem: parse `/proc/pressure/{io,memory}` avg10
   - tcp_estab: parse `ss -s` ou `/proc/net/tcp` count ESTAB
   - fd_used, fd_max: parse `/proc/sys/fs/file-nr`
   - net_rx_kbs, net_tx_kbs: delta de `/sys/class/net/wg0/statistics/rx_bytes`
     em janela de 60s (ou eth0 se wg0 não existir)
   - cpu_throttled_total: parse `cpu.stat` nr_throttled do user.slice
   - oom_recent: `dmesg --since="-1 min" | grep -ci "killed\|oom"`
   - jrn_blocked: `journalctl --disk-usage` parse size, alert se > 1GB
   - n_procs: `len(list(Path('/proc').iterdir()))` filtrando ^[0-9]+$
   - top_cpu_*: `ps -eo comm,pcpu --sort=-pcpu | head -2 | tail -1`
   - top_mem_*: `ps -eo comm,rss --sort=-rss | head -2 | tail -1`
7. **Função `prune_old_samples(db, retention_days)`** — roda a cada 1h:
   `DELETE FROM samples WHERE ts < datetime('now', '-N days')`
8. **Função `detect_anomalies(sample, history)`** — implementação stub
   (placeholder, real vem em 09-02): retorna lista de (level, msg)
9. **Função `respond(anomalies, config)`** — stub (real em 09-03 e 09-05):
   log apenas
10. **Main loop** com signal SIGTERM/SIGINT, poll = config['RG_MG_POLL_INTERVAL_SEC'],
    write sample → DB → detect → respond → sleep
11. **PID file** em `/run/user/1001/mission-guardian.pid` (opcional, para stop limpo)
12. **Log path**: `~/.logs/resource-governor/mission-guardian.log`
    usando `append_log` helper (copy do watchdog)

Criar `modules/srv1-ops/configs/mission-guardian.env`:
```
# Mission Guardian — defaults
RG_MG_POLL_INTERVAL_SEC=60
RG_MG_DB_PATH=/home/ubuntu/.local/state/omni/mission-guardian.db
RG_MG_RETENTION_DAYS=30
RG_MG_FALLBACK_TELEGRAM_CHAT=
RG_MG_FALLBACK_INVIOLABLE_HOOK=/home/ubuntu/scripts/inviolable-watchdog.sh
```

Criar `.config/systemd/user/mission-guardian.service`:
```ini
[Unit]
Description=ATIUS-SRV-1 Mission Guardian (24/7 monitor + auto-tune + incident response)
After=network-online.target
Wants=network-online.target

[Service]
Type=oneshot
ExecStart=/usr/bin/python3 /home/ubuntu/GitHub/omni-srv-admin/modules/srv1-ops/scripts/mission-guardian.py
Nice=-5
OOMScoreAdjust=-1000
OOMPolicy=continue
StandardOutput=append:/home/ubuntu/.logs/resource-governor/mission-guardian.log
StandardError=append:/home/ubuntu/.logs/resource-governor/mission-guardian.log

[Install]
WantedBy=default.target
```

Criar `.config/systemd/user/mission-guardian.timer`:
```ini
[Unit]
Description=ATIUS-SRV-1 Mission Guardian timer (every 60s)

[Timer]
OnBootSec=60s
OnUnitActiveSec=60s
AccuracySec=5s
Persistent=true

[Install]
WantedBy=timers.target
```

Após criar:
1. `chmod +x modules/srv1-ops/scripts/mission-guardian.py`
2. `XDG_RUNTIME_DIR=/run/user/1001 systemctl --user daemon-reload`
3. `XDG_RUNTIME_DIR=/run/user/1001 systemctl --user enable --now mission-guardian.timer`
4. Aguardar 5min, verificar:
   - `sqlite3 ~/.local/state/omni/mission-guardian.db "SELECT count(*), min(ts), max(ts) FROM samples"`
     deve retornar count >= 3, ts spans >= 3min
   - `tail -5 ~/.logs/resource-governor/mission-guardian.log` deve mostrar
     múltiplas linhas `mission-guardian-sample ts=... load1=...`
