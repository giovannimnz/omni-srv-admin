# Phase 14 Plan 05: Jenkins + servicos orfaos: remover deps Docker e validar em dominio publico

## Performance

- **Duration:** ~30 min
- **Started:** 2026-06-15T11:24:00Z
- **Completed:** 2026-06-15T11:28:00Z
- **Tasks:** 4
- **Files modified:** 2 live + 3 planning

## Goal

Eliminar dependencias Docker-orfas (`/var/run/docker.sock`, `/usr/bin/docker`)
em servicos que ja migraram para Podman, comecando pelo Jenkins. Garantir
que o servico sobe 100% via systemd user unit, responde no dominio publico
`https://jenkins.atius.com.br/` e o plano fica registrado no M006 pra que
o ciclo de validacao externa seja padrao de futuros servicos.

## Motivation

O cutover Docker→Podman (2026-06-12) deixou varios `podman-compose.yml`
e systemd units com `volumes: - /var/run/docker.sock:/var/run/docker.sock`
e `-v /usr/bin/docker:/usr/bin/docker`. Quando o daemon Docker foi
desinstalado, esses paths sumiram do host e os units passaram a falhar
com `exit-code, status=125` (`statfs /var/run/docker.sock: no such file
or directory`). O Jenkins estava nesse estado: `systemctl --user status
container-jenkins.service` mostrava `failed` com 9+ restart attempts
bloqueados pelo `Start request repeated too quickly`.

## Tasks

### Task 1: Backup do estado live

- Backup do unit atual: `container-jenkins.service.bak.20260615_HHMMSS`
- Backup do compose: `podman-compose.yml.docker-deps-20260615.bak`

### Task 2: Reescrever unit + compose sem deps Docker

- Remover `-v /var/run/docker.sock:/var/run/docker.sock`
- Remover `-v /usr/bin/docker:/usr/bin/docker`
- Manter `/usr/lib/aarch64-linux-gnu/libltdl.so.7` (lib do agente Jenkins)
- Manter `/home/ubuntu/GitHub/atius` (workspace read-only)
- Adicionar comentario no unit explicando a remocao (motivo: Docker desinstalado)

### Task 3: Subir o servico e validar

- `systemctl --user daemon-reload`
- `systemctl --user reset-failed container-jenkins.service`
- `systemctl --user start container-jenkins.service`
- `podman logs --tail jenkins` → checar `Jenkins is fully up and running`
- `curl -I http://127.0.0.1:8085/` → esperar 403 com `x-jenkins: 2.541.3`
- `curl -L https://jenkins.atius.com.br/login` → esperar HTML do login form
  com theme dark `https://jenkins.atius.com.br/theme-dark/theme.css`

### Task 4: Adicionar ao planning do M006

- 14-VALIDATION.md: registrar que 14-05 esta complete (link para este plan)
