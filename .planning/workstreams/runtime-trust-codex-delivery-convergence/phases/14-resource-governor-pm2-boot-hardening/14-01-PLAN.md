Garantir que as correcoes live do `resource-governor` e
`inviolable-watchdog` estao completas no repo, cobertas pelo installer/status e

## tasks

### Task 1: reconcile repo artifacts against live fix

Confirmar que cada item da secao "Correcoes aplicadas" da nota esta presente no
repo:

- `resource-governor-cgroup-init.service` e `resource-governor-patcher.service`
  nao dependem de `default.target`.
- `resource-governor-cgroup-init.sh` aplica CPU, I/O, `cpu.weight`,
  `io.weight`, `memory.high`, `memory.max` e `memory.swap.max`.
- `resource-governor-patcher.py` le `resource-governor.env` e runtime override.
- `resource-governor-watchdog.py` remove estado conservador obsoleto sem zerar
  limites quando nao ha override.
- `inviolable-watchdog.service` usa `KillMode=process`, `TimeoutStartSec=120`
  e script versionado do repo.
- `inviolable-watchdog.timer` usa `OnUnitInactiveSec=30s`.
- `inviolable-watchdog.sh` usa `systemctl --no-block`, transient units para
  XRDP/SSHD, ecosystems reais para ATS/Horistic e ignora nginx ausente.

### Task 2: improve install/status guardrails

Atualizar `cli/omni/srv1_ops.py` e docs se faltar:

- `omni srv1 resources install --dry-run` lista todos os units novos.
- install real usa `systemctl --user enable --now` apenas para governor e
  inviolable units desta fase.
- status mostra runtime mode, runtime override path, services, timers, slices,
  cgroups diretos e jobs presos relevantes.
- status sinaliza explicitamente quando algum unit suportado ainda aponta para
  `/home/ubuntu/ecosystem.atius.js`.
