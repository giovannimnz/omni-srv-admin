# Plan 41-01: TEI/GTE Backend, New API Alias, OpenAI Smoke and Client Migration Contract

<objective>
Create a local OpenAI-compatible embeddings path for Atius clients. The executor must deploy or stage TEI for `Alibaba-NLP/gte-multilingual-base` in k3s on the `horistic-srv` worker, configure New API to expose `embedding-pt-v1` at `https://router.atius.com.br/v1`, validate the endpoint with real POST `/v1/embeddings`, and document safe migration for GBrain, Obsidian and Graphify without leaking secrets or mixing vector dimensions.
</objective>
