## Scope Justification

Plan 42-02 intentionally keeps the ATS facade, callback, backend bridge, middleware, and logout wiring together even though the file count is above the warning threshold. These files form one session contract: splitting frontend callback routing from backend cookie issuance or logout wiring would let an executor pass partial tests while breaking the actual `auth-token` handoff. The plan remains bounded because it excludes Apache, Cloudflare, DNS, Keycloak client mutation, PM2, production env files, package installs, and all non-ATS app migrations.
