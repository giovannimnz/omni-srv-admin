# Plan 34-02: WireGuard/CoreDNS forwarding and first real Linux host enrollment

<objective>
Turn the private FreeIPA server on `atius-srv-3` into a WireGuard-reachable
service for the fleet, then enroll the first real Linux host (`atius-srv-3`)
with rollback and basic group/sudo evidence.
</objective>

<tasks>

<task id="T1" type="ops">
<title>Back up CoreDNS and FreeIPA gateway state before mutation</title>
<action>
Create timestamped backups of the live CoreDNS `Corefile` on `atius-srv-2`,
the relevant FreeIPA container/gateway state on `atius-srv-3`, and the local
planning docs before changing DNS forwarding or host enrollment.
</action>
</task>

<task id="T2" type="ops">
<title>Publish `atius.internal` privately to WireGuard clients</title>
<action>
Update CoreDNS on `atius-srv-2` so only the `atius.internal` zone is forwarded
to `10.1.1.3`, while the fleet default DNS path remains unchanged. On
`atius-srv-3`, publish the FreeIPA container privately on the WireGuard IP
`10.1.1.3` for DNS, Kerberos, LDAP and HTTP(S) only. Do not expose FreeIPA
publicly.
</action>
</task>

<task id="T3" type="ops">
<title>Enroll `atius-srv-3` as the first real Linux client</title>
<action>
Use the root-only FreeIPA bootstrap secret on `atius-srv-3` to enroll the host
as `atius-srv-3.atius.internal`. Preserve rollback evidence for hostname,
resolver, and client uninstall. Do not touch `horistic-srv` yet.
</action>
</task>

<task id="T4" type="validation">
<title>Validate DNS, enrollment, and basic group/sudo behavior</title>
<action>
Capture proof that `atius-srv-3` resolves `ipa.atius.internal` through the
CoreDNS + WireGuard path, that `ipa-client-install` succeeded on the real host,
and that NSS/group/sudo basics work for the pilot realm user path.
</action>
</task>

<task id="T5" type="tracking">
<title>Write closeout artifacts and update planning state honestly</title>
<action>
Write `34-02-SUMMARY.md`, refresh `34-VERIFICATION.md`, and update
`docs/domain/freeipa-dns-client-enrollment.md`, `.planning/workstreams/runtime-trust-codex-delivery-convergence/REQUIREMENTS.md`,
`.planning/workstreams/runtime-trust-codex-delivery-convergence/ROADMAP.md`, and `.planning/workstreams/runtime-trust-codex-delivery-convergence/STATE.md` only with the result actually
reached.
</action>
</task>

</tasks>

<must_haves>
- FreeIPA remains private to WireGuard/private routing only.
- CoreDNS forwarding is scoped to `atius.internal`, not a global DNS takeover.
- The first real host is `atius-srv-3`, per operator approval.
- Rollback is captured before enrollment and before DNS forwarding changes.
- `horistic-srv` is deferred until the `srv3` pilot is proven stable.
</must_haves>

<verification>
- `dig` against `10.1.1.2` resolves `ipa.atius.internal` and realm SRV records.
- `ipa-client-install` succeeds on `atius-srv-3`.
- `kinit admin`, `ipa ping`, `getent`, `id`, and `sudo -l -U admin` provide
  basic group/sudo evidence on the enrolled host.
- No public FreeIPA exposure is introduced.
</verification>
