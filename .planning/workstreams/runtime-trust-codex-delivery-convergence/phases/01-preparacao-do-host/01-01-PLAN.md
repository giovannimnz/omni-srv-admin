1. Install chrony:
```bash
sudo apt install -y chrony
```

2. Write chrony.conf with Oracle Cloud NTP + public fallback:
```bash
sudo tee /etc/chrony/chrony.conf > /dev/null << 'EOF'
# Oracle Cloud Infrastructure NTP (primary)
server 169.254.169.254 iburst prefer

# Public NTP pools (fallback)
pool ntp.ubuntu.com iburst
pool pool.ntp.org iburst

# Record clock drift
driftfile /var/lib/chrony/chrony.drift

# Allow clock step in first 3 updates
makestep 1.0 3

# Enable kernel RTC sync
rtcsync
EOF
```

3. Enable and start chrony:
```bash
sudo systemctl enable --now chrony
```

4. Wait 10 seconds for initial sync, then verify:
```bash
sleep 10
chronyc sources -v
chronyc tracking
```

5. Confirm sync status — look for "Leap status" = "Normal" in chronyc tracking output.
