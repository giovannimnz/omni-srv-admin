  <name>Task 1: Disable systemd-resolved stub listener on port 53 (per D-10, D-11)</name>
  <files>/etc/systemd/resolved.conf, /etc/resolv.conf</files>
  <read_first>
    - /etc/systemd/resolved.conf
    - /etc/resolv.conf
    - /etc/cloud/cloud.cfg
  </read_first>
  <action>Disable systemd-resolved's stub listener on 127.0.0.53:53 so FreeIPA BIND can use port 53 (per D-10). CRITICAL: preserve upstream DNS configuration and prevent cloud-init from overwriting.

Step 1 — Read current state:
```bash
cat /etc/systemd/resolved.conf
cat /etc/resolv.conf
ls -la /etc/resolv.conf  # check if symlink
```

Step 2 — Disable stub listener (edit DNSStubListener):
```bash
sudo sed -i 's/^#DNSStubListener=yes/DNSStubListener=no/' /etc/systemd/resolved.conf
```
Verify the change:
```bash
grep 'DNSStubListener' /etc/systemd/resolved.conf
# Should show: DNSStubListener=no
```

Step 3 — Preserve upstream DNS servers in resolved.conf:
```bash
sudo sed -i 's/^#DNS=.*/DNS=10.1.1.2 169.254.169.254/' /etc/systemd/resolved.conf
```
Verify:
```bash
grep '^DNS=' /etc/systemd/resolved.conf
# Should show: DNS=10.1.1.2 169.254.169.254
```

Step 4 — Prevent cloud-init from overwriting /etc/resolv.conf:
```bash
sudo sed -i 's/manage_resolv_conf: true/manage_resolv_conf: false/' /etc/cloud/cloud.cfg 2>/dev/null || echo "cloud-init resolv management already disabled or file not found"
```

Step 5 — Restart systemd-resolved:
```bash
sudo systemctl restart systemd-resolved
```

Step 6 — Verify port 53 is free:
```bash
ss -ulnp | grep ':53 '
# Should show NOTHING on 127.0.0.53:53
```

Step 7 — Verify DNS resolution still works:
```bash
dig @10.1.1.2 google.com +short
# OR if resolv.conf points to 10.1.1.2:
dig google.com +short
# Should return IP addresses
```

Step 8 — Verify systemd-resolved is still running (service up, just stub disabled):
```bash
systemctl is-active systemd-resolved
# Should return "active"
```

Step 3 — If credentials exist, query Cloudflare API to discover current Origin Rules:
```bash
# Get zone info
curl -s "https://api.cloudflare.com/client/v4/zones" \
  -H "Authorization: Bearer $CF_API_TOKEN" \
  -H "Content-Type: application/json" | \
  jq '.result[] | {name: .name, id: .id}' 2>/dev/null

# If zone found, get rulesets
ZONE_ID=$(curl -s "https://api.cloudflare.com/client/v4/zones?name=atius.com.br" \
  -H "Authorization: Bearer $CF_API_TOKEN" \
  -H "Content-Type: application/json" | \
  jq -r '.result[0].id' 2>/dev/null)

if [ -n "$ZONE_ID" ] && [ "$ZONE_ID" != "null" ]; then
  curl -s "https://api.cloudflare.com/client/v4/zones/$ZONE_ID/rulesets" \
    -H "Authorization: Bearer $CF_API_TOKEN" \
    -H "Content-Type: application/json" | \
    jq '.result[] | {id: .id, name: .name, phase: .phase, description: .description}' 2>/dev/null
fi
```
