<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| local-command-output-to-parser | Package manager, PM2, systemd and container outputs are untrusted text/JSON. |
| collector-to-DbOmniFleet | Agent writes observations through PgBouncer. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-23-02-01 | Tampering | collector subprocesses | mitigate | Explicit read-only command allowlist, no mutating verbs, timeouts. |
| T-23-02-02 | Denial of Service | slow package commands | mitigate | Short subprocess timeouts and warnings instead of hard failure. |
| T-23-02-03 | Information Disclosure | command output/audit | mitigate | Redact secret-like keys and raw output before audit/DB metadata. |
| T-23-02-04 | Tampering | DB path | mitigate | Use existing `_db_env()` PgBouncer enforcement only. |
| T-23-02-SC | Tampering | package installs | accept | No dependency installs in this plan. |
</threat_model>
