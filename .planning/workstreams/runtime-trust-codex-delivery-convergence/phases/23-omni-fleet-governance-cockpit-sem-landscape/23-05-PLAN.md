<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| browser-to-Landscape | Operators access a machine-management UI over HTTP/S. |
| Landscape-to-clients | Landscape client registration gives server-side control visibility over hosts. |
| deployment-to-cluster | Podman/K3s packaging can affect ports, storage, ingress and resources. |
| secrets-to-runtime | Pro/licensing/cert/registration material must reach runtime without entering git/docs/logs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-23-05-01 | Spoofing/Elevation | Landscape UI | mitigate | TLS, Access/auth policy and no anonymous public admin UI. |
| T-23-05-02 | Denial of Service | host/cluster resources | mitigate | Preflight resource budget, limits and rollback before deploy. |
| T-23-05-03 | Information Disclosure | Pro/licensing/cert keys | mitigate | Store only `secret_ref`/runtime paths in repo docs; redact validator output. |
| T-23-05-04 | Tampering | client registration/update control | mitigate | Enroll clients only after operator approval and document interaction with Omni update gates. |
| T-23-05-SC | Tampering | package installs/container deploy | mitigate | Live install/deploy is checkpoint-gated and must have backup/rollback. |
</threat_model>
