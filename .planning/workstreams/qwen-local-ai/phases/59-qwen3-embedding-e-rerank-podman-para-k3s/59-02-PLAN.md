## Scope Exception Rationale

The artifact lock, oracle selection, reranker behavior, package lock and image are one atomic inference seam: splitting them across waves would allow a tested server to diverge from the model/package/image hashes consumed by rollout. Tasks serialize risk as lock/oracle → service/package tests → image/gate. Failure before the final task discards candidate artifacts; Wave 1 performs no production route mutation. Execution-generated JSON evidence is intentionally omitted from `files_modified` source-edit scope and remains enumerated in task artifacts.
