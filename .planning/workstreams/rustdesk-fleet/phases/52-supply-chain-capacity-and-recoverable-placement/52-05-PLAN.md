## Artifacts this phase produces

- Three candidate JSON records with identical ordered stage schema: `supply`, `capacity`, `vault`, `backup`, `restore`, `capacity_finalize`, `rollback`, `topology_security`; each has `status`, `observed_at`, `input_digest`, `evidence_ids`, redacted findings and scoped mutation metadata. A prior failure yields an explicit `SKIPPED_DUE_TO_GATE` for unsafe later stages, safe rollback for any disposable drill artifacts already created, and an overall current `NO-GO`.
- Each reached `capacity_finalize` records fresh `used1_bytes`, filesystem source/mount, inode counters/currentness, actual backup A/B sizes, checked reconciliation of materialized bytes against reserved terms, remaining unmaterialized log/state/image terms, overflow/same-mount checks, and the final 80% integer inequality.
- Each executed backup stage embeds manifests `backups.a` and `backups.b`: independently generated timestamps/process IDs, distinct destination classes, input digests, archive SHA-256, allowlisted state/modes/sizes, verification, retention and `secret_material_present=false`.
- Restore/rollback sections record consumed archive digest, fresh runtime/directory IDs, pinned ARM64 image, SQLite integrity, source/restored public fingerprints, no-public-listener proof, inactive cleanup and unchanged legacy paths.
- `full-gate-summary.json` records strict attempt order, persisted predecessor NO-GO digests, first full PASS or no-primary, and `windows_install_performed=false`.

## Trust Boundaries

| Boundary | Description |
|---|---|
| candidate observation -> serial fallback | Current persisted NO-GO controls reachability of the next host. |
| Vault -> ephemeral runtime | Secret values cross only into protected tmpfs and never evidence. |
| state -> local/GDrive backups | Only allowlisted non-secret state crosses into two independent recovery media. |
| backup + Vault -> fresh runtime | Restore must reproduce state and identity without public exposure. |

| T52-FALLBACK | Repudiation/DoS | candidate chain | high | mitigate | Atomic full stage vector and persisted predecessor NO-GO; all later-stage failures continue fallback. |
| T52-CLEANUP | Tampering/DoS | Atius storage | high | mitigate | D-06 rejects destructive/unallowlisted commands and records the exact bounded reversible post-capacity writes separately from remediation. |
| T52-CAP-FINAL | Tampering/DoS | final capacity reconciliation | high | mitigate | Fresh same-mount used1/inodes, checked materialized-byte reconciliation, A/B reserve limits and remaining-reservation 80% inequality before selection. |
