<threat_model>
**Security enforcement:** OWASP ASVS L1 on Vault/runtime/restore boundaries; every critical/high threat is mitigated and blocks on failure.

## Trust Boundaries

| Boundary | Description |
|---|---|
| Vault -> ephemeral process/tmpfs | Secret values cross only into short-lived protected runtime, never evidence. |
| ephemeral identity -> isolated hbbs | Identity is consumed by pinned binary without public exposure. |
| quiesced state -> backup archives | Only allowlisted non-secret state crosses into retained recovery media. |
| archive + Vault -> fresh restore | Recoverability requires independent state bytes and authoritative identity to converge. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T52-VAULT-ACCESS | Spoofing/Elevation | helper authorization | high | mitigate | Exact six approved refs, authenticated stdin-safe helper and metadata-only result. |
| T52-VAULT-LEAK | Information Disclosure | argv/stdout/runtime | critical | mitigate | No positional values, tmpfs 0700/0600, xtrace off, sentinel tests, cleanup trap and secret scanner. |
| T52-DISTINCTNESS | Information Disclosure | password comparison | high | mitigate | Fresh in-memory HMAC and aggregate count only; no per-value/reusable hash leaves process. |
| T52-BACKUP-KEY | Information Disclosure | backup archives | critical | mitigate | State allowlist excludes identity/passwords and archive content scanner blocks any key material. |
| T52-BACKUP-CORRUPT | Tampering/DoS | SQLite/archives | high | mitigate | Quiesce, integrity check, two independent hashes, content/mode verification and retain-on-failure. |
| T52-RESTORE-ID | Spoofing/Tampering | restored identity | high | mitigate | Rehydrate from Vault and require exact public fingerprint equality with source/contract. |
| T52-RESTORE-NET | Elevation/DoS | disposable runtime | high | mitigate | No published/public network, listener negative test and stopped/disabled cleanup proof. |
| T52-SC | Tampering | package-manager installs | low | accept | No package-manager install is needed; only pinned prebuilt artifacts are consumed. |
</threat_model>
