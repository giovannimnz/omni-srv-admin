**Security enforcement:** OWASP ASVS 5.0.0 Level 1 baseline plus the risk-based Level 2 V16 subset for logging inventory, sensitive-data exclusion, security-event coverage, log protection and fail-secure errors. Blocking threshold is `high`; any unresolved high finding makes this plan and Phase 52 advancement `BLOCKED` with exit code 2.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator review -> product decision | Human statements about mandatory controls cross into the deterministic OSS/Pro state machine. |
| versioned contract -> validator | Untrusted JSON/Markdown paths, types, enums and duplicate keys enter the trusted validation layer. |
| Vault authority -> repo references | Only role/path/field names cross; private key and password values never enter repository/evidence space. |
| permission contract -> later clients | Desired local profiles cross a product boundary that OSS cannot claim to enforce centrally. |
